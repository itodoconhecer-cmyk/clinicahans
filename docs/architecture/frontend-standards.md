# Padrões de Frontend

## Stack
- HTML5
- CSS3
- JavaScript moderno puro
- ES Modules
- Fetch API

## Estrutura recomendada
- pages/views
- components
- services
- state
- utils
- assets

## Diretrizes
- baixa complexidade por módulo;
- serviços centralizados para API;
- feedback claro de erro, sucesso, carregamento e vazio;
- autenticação desacoplada da UI;
- responsividade e acessibilidade básica;
- visual moderno, claro e coerente com o domínio;
- não introduzir framework sem decisão registrada.
